# EQ2Emu — Live In-Game Content Placement Tool Ralph Loop

## Mission

Create a production-ready live in-game content placement system for EQ2Emu that allows rapid creation and editing of:

* NPC spawns
* enemy camps
* harvestables
* ground objects
* collections
* patrol points
* spawn groups

The system must work with the existing EQ2 client as a black box and require no client modifications.

The tool must:

* support live editing while logged into the game
* persist changes to the database
* avoid gameplay/business logic modifications
* support rapid iteration
* minimize server restart requirements

---

# Core Design Philosophy

The EQ2 client is treated purely as:

* a viewport
* a movement/input system
* a world visualization layer

All tooling logic exists server-side or externally.

The player character itself becomes the editor cursor.

---

# Non-Goals

The following are explicitly forbidden:

* changing packet serialization behavior
* modifying combat systems
* changing quest logic
* changing NPC AI behavior
* altering client UI assets
* DLL injection into the client
* modifying rendering behavior
* replacing existing spawn systems

This project only adds tooling and workflows.

---

# Success Criteria

The tool is complete when a GM can:

1. Enter placement mode
2. Spawn preview entities
3. Move entities live in-world
4. Save entities directly to DB
5. Edit existing entities
6. Clone entities
7. Delete entities
8. Reload entities without restarting worldserver
9. Persist placements correctly across reboot
10. Complete all workflows without manual SQL editing
